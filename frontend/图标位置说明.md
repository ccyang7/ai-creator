# 图标位置说明文档

## 📋 概述

本文档列出所有页面中使用的图标位置，方便后续替换为自定义图标或 Logo。

**重要说明**: 当前所有图标已临时使用 Emoji 文字代替，方便后续统一替换为自定义图标或 SVG。

## 🎨 建议替换的图标

### 高优先级

1. **Logo**: `src/assets/logo.svg` - 网站主 Logo
2. **AI 图标**: ⚡ - 可替换为自定义 AI 图标或品牌标识
3. **应用占位图**: 🚀 - 可替换为默认应用图标

### 中优先级

1. **功能图标**: 所有按钮上的文字可替换为图标 + 文字的组合
2. **类型标签**: ⚡ 可替换为不同类型的专属图标
3. **装饰图标**: 🔥⭐👑 等可替换为更符合品牌风格的图标

### 推荐图标库

- **Ant Design Icons**: https://icons.ant-design.vue.org/
- **使用方式**:

  ```vue
  import { IconNameOutlined } from '@ant-design/icons-vue'

  <IconNameOutlined />
  ```

---

## 📝 替换步骤

1. 确定要替换的图标位置
2. 选择合适的图标组件或准备 SVG 文件
3. 替换对应的 Emoji 文字为图标组件
4. 调整图标大小和颜色样式
5. 测试显示效果
